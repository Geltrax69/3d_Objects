# 3d_Objects

3D models for use in Spline (and anywhere `.glb` works).

## Models (`models/`)

| File | Contains |
|---|---|
| `background.glb` | The background stack: terracotta rectangle (box), dark circle (disc), blue cylinder, on a studio floor |
| `apple_text.glb` | The extruded 3D **APPLE** text on its own — import separately so you can move it around independently |
| `test_scene.glb` | Everything together, the full staged scene |

## Using in Spline

1. Drag `background.glb` into your Spline scene — that's your backdrop.
2. Drag `apple_text.glb` in as a second object — now the text is its own
   layer and you can move, rotate, or scale it freely without touching the
   stack.

## Previews (`previews/`)

Rendered previews of the full scene from two angles.

## Website (`website/`)

A React + three.js site that shows the 3D scene as a full-viewport
background with headline text in front. Run it with:

```
cd website
npm install
npm run dev
```

## Building (`scripts/`)

The scene is generated by `scripts/test_scene_stack.py` (Blender 5.2.2,
headless). Run it with:

```
blender --background --python scripts/test_scene_stack.py
```

Set `SKIP_RENDER=1` to skip the preview renders and only re-export the
`.glb` files.
